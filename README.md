IYANAR SELVAM CHIT FUND – MOCK WEBSITE
======================================

OPEN ON YOUR COMPUTER
1. Unzip this folder.
2. Double-click "index.html". It opens in your browser (Chrome recommended).
   Keep the "assets" folder next to index.html – it holds the logo and images.
   Internet is needed for the fonts to load.

SHARE A LINK WITH THE CLIENT (free, about 1 minute)
1. Go to https://app.netlify.com/drop
2. Drag this whole "iyanar-selvam-website" folder onto the page.
3. You get a link like https://something.netlify.app
4. Sign up (free) to rename it, e.g. https://iyanarselvam.netlify.app

USE THE CLIENT'S OWN DOMAIN LATER
Upload the same files to any web hosting (Hostinger, GoDaddy, etc.)
or connect the domain in Netlify (Site settings > Domain management).
